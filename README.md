# FGOAC-scooby

**FGOAC-scooby** is the English launcher and patch for Fate/Grand Order Arcade on PC. fgoac pc local platform after the cabinet shutdown.

## What's new in v1.01 (September 2026)
- Public 1.00 mid-September, 1.01 follow-up
- English launcher over the local platform
- Story, farming, events, in-client gacha offline
- Controller support; NVIDIA usually boots clean

## How to use
1. Download v1.01.
2. Extract `FGOAC-scooby.zip`.
3. Run `FGOAC-scooby.exe`.
4. Point it at the FGOAC data folder. Play.
